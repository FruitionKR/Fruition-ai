# 0041. 편입·답변이 원문 조건을 지키고 추론하지 않기

## 맥락
Jev 평가(2026-10-30, Haiku)에서 답변을 원자 주장으로 나눠 corpus 원문과 대조했더니, Wiki RAG 답변(Jev 켬)의 근거 없는 주장 비율이 4.8%(1,782개 중 85개)로 원문 청크만 쓰는 일반 RAG 3.4%(1,780개 중 60개)보다 높았다. 85개의 출처를 답변 문맥과 대조하면 다음과 같았다.

- 56개는 문맥에 없었다. 답변 모델이 원문에 없는 계산·유래·결론을 덧붙였다.
- 20개는 편입이 만든 근거 단위(관찰 요약·근거 주장)에서 왔다. 원문 조건("대통령령으로 정하는")을 빠뜨리거나, 따로 적힌 두 사실을 인과("~하여 기본값")로 묶거나, 노력 의무를 단정으로 바꿨다.
- 개념 페이지 정의에서 온 것은 3개, 원문 블록에서 온 것은 6개였다.

화면은 이미 인용 원문 블록을 보여 준다. 그러나 근거 단위와 답변 본문이 원문을 바꿔 쓰면 사용자는 바뀐 문장을 먼저 읽는다.

## 결정
- 추출·채팅 추출·패치·개념 페이지 생성 프롬프트에 충실성 규칙을 둔다. 원문 블록이 말한 것만 쓰고, 원문에 없는 원인·이유·목적·결과·비교를 더하거나 따로 적힌 문장을 인과·조건 하나로 묶지 않는다. 조건·예외·적용 범위·수량·의무 정도(must, may, should, try to)는 그대로 두고 강하게도 약하게도 바꾸지 않는다. 조건과 함께 담기에 길면 조건을 빼지 말고 주장을 나눈다.
- 편입 평가기는 조건을 바꾸거나 원문에 없는 인과를 쓴 항목을 `unfaithful_claim` 경고(`warnings`)로만 남긴다. 불합격·재시도로 이어지지 않는다.
- 질의 답변 생성 규칙에 근거가 말하지 않은 원인·이유·계산·결론을 추론하지 않고, 근거의 조건·예외·의무 정도를 유지한다는 규칙을 더한다.

## 대안과 기각 사유
- **`unfaithful_claim`을 high 문제로 두고 재시도:** 재시도가 늘어 편입 시간이 길어진다(평가에서 30쪽 문서 편입에 약 11분). 얼마나 자주 걸리는지 경고로 먼저 본다.
- **답변 문맥에 근거 단위 대신 원문 블록 넣기:** 화면이 이미 인용 원문 블록을 보여 주므로, 근거 단위와 답변이 원문을 바꾸지 않게 하는 쪽을 고쳤다.

## 결과
- 근거 단위와 개념 페이지가 원문 조건·의무 정도를 유지하고, 답변이 문맥 밖 결론을 덧붙이지 않도록 지시한다. 프롬프트 지시라 지켜지는지는 주장 단위 대조로 다시 재야 한다.
- `unfaithful_claim` 경고는 편입 평가 결과에 남는다. 빈도가 높으면 high로 올릴지 다시 정한다.
